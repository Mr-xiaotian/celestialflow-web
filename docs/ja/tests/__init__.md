# tests/__init__.py

> 📅 最終更新日: 2026/09/24

## 役割
`tests/` は CelestialFlow Web 層のインターフェースとページ統合の挙動をカバーし、状態スナップショットの分離、状態の取得/プッシュ、グラフメタ情報の同期、設定の取得、タスク注入、エラーのページネーション/フィルタ、グラフコンテキストの切り替え、および期限切れプッシュの無視が安定していることを保証します。

## 含まれるファイル
- `__init__.py`: 空ファイルで、`tests/` を Python パッケージとして識別するためだけに使用され、テストコードや共有ロジックは含みません。
- `conftest.py`: `web_server` と `client` の2つの Pytest Fixture を提供します。
- `test_server.py`: スナップショット分離、ダッシュボードトップページ、フロントエンドモジュール評価順序、設定 API、状態とグラフメタ情報の同期、タスク注入、エラーページネーションなどの Web API 統合テストをカバーします。

## 実行方法

```bash
# すべて実行
uv run pytest tests -v

# server 統合テストのみ実行
uv run pytest tests/test_server.py -v
```
