# src/celestialflow_web/static/css/dashboard_statuses.css

> 📅 最終更新日: 2026/09/24

ダッシュボードのノード状態カードのレイアウトとスタイル定義を担当し、統計グリッド、四段式プログレスバー、およびノード状態に基づく動的な枠線色を含みます。

> 注: ノード実行モード/並行数などのビルド時メタ情報は、グラフメタ情報内の `node_meta` に由来し、`dashboard_statuses.ts` が `.stat-value` を通じてレンダリングします。本 CSS ファイルには新しいセレクタは導入されていません。


## レイアウト構造

### 統計グリッド (`.stat-grid`)
- `grid` レイアウトを使用し、二列に固定します。
- 成功、待機、エラー、重複などのコア指標を表示するために使用します。

### ノードカード (`.node-card`)
- 角丸カード設計を採用します（`border-radius: 1rem`）。
- **状態枠線**: 左側に 3px 幅の状態バーを設け、色はノード実行状態に応じて動的に変化します:
  - `.status-running`: `--cornflower-400` (青) を使用し、実行中であることを示します。
  - `.status-stopped`: `--carbon-400` (グレー) を使用し、停止済みであることを示します。
  - デフォルト: `--carbon-300` を使用し、未起動であることを示します。

## プログレスバーのレンダリング (`.progress-bar`)

プログレスバーは四つのセグメント（`.progress-segment`）で構成され、それぞれ異なるタスク状態の色に対応します:

| クラス名 | 対応する指標 | ライトモードの色 | ダークモードの色 |
|------|----------|--------------|--------------|
| `.seg-success` | 成功 | `--jade-400` | `--jade-700` |
| `.seg-error` | エラー | `--crimson-400` | `--crimson-700` |
| `.seg-duplicate` | 重複 | `--marigold-400` | `--marigold-700` |
| `.seg-pending` | 待機 | `--carbon-300` | `--carbon-600` |

## 時間推定エリア (`.time-estimate`)

- 揃えを確保するため等幅フォント（`monospace`）を使用します。
- `.elapsed` シリーズのクラス名は、経過時間の各桁をセグメントごとに着色する（成功、エラー、重複）ために使用します。

## インタラクション効果

- **クリックフィードバック**:
  - `.error-clickable`: エラー数値項目にハンド型カーソル（`pointer`）を表示し、クリックして遷移可能であることを示唆します。

## レスポンシブ設計

- 幅が `2048px` 未満のとき、`#dashboard-grid` は単一カラムレイアウトに切り替わります。
- 長いタイトルの折り返しロジックを自動的に処理します。
