# src/celestialflow_web/static/css/dashboard_summary.css

> 📅 最終更新日: 2026/09/24

ダッシュボード右下の「全体状態サマリー」パネルのスタイル定義を担当し、色彩豊かな統計カードでグローバルな実行指標を表示します。

## レイアウト構造 (`.summary-grid`)

- `grid` レイアウトを使用し、二列に固定します。
- 各グリッドセルは一つの `.summary-item` を含みます。

## 統計カード (`.summary-item`)

各統計項目はその意味に応じて異なるテーマ色が割り当てられ、背景色（`.summary-item`）と数値の文字色（`.summary-value`）を含みます:

| 統計項目 | クラス名 | メインカラー | 意味 |
|--------|------|--------|------|
| **総成功タスク** | `.success` | `Jade` (緑) | タスクが順調に完了 |
| **総待機タスク** | `.pending` | `Carbon` (灰) | キュー内で処理待ち |
| **総エラータスク** | `.error` | `Crimson` (赤) | 処理に失敗、要注意 |
| **総重複タスク** | `.duplicate` | `Marigold` (橙) | 重複排除ロジックに命中 |
| **アクティブノード** | `.nodes` | `Cornflower` (青) | 現在実行中の Stage 数 |
| **総残り時間** | `.remain` | `Violet` (紫) | グローバルな進捗の推定 |

## スタイル特性

- **視覚的階層**: 数値は `2rem` の太字フォント、ラベルは `0.75rem` のグレーの小さい文字を採用します。
- **ダークモード**: 背景色を自動的に暗色系（`900` シリーズなど）に切り替え、文字色を淡色系（`300` シリーズなど）に切り替えて、コントラストを確保します。
- **インタラクションの示唆**: 
  - 総エラー数が 0 より大きいとき、`.summary-value.error-clickable` はハンド型カーソルを表示し、ユーザーをクリックしてエラー詳細へ遷移するよう誘導します。
