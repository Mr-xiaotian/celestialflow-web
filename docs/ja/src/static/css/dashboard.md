# src/celestialflow_web/static/css/dashboard.css

> 📅 最終更新日: 2026/09/24

ダッシュボードページのコアとなる三列レイアウトアーキテクチャを担当します。

## レイアウトアーキテクチャ (`.three-column-container`)

ダッシュボードはワイドスクリーンの三列設計を採用し、`flex` レイアウトによってページを構造的に表示します:

- **左パネル (`.left-panel`)**: 割合 25%。通常は「構造図」と「グラフ分析情報」カードを配置します。
- **中央パネル (`.middle-panel`)**: 割合 40%。コア領域で、「ノード実行状態」カードのグリッドを表示するために使用します。
- **右パネル (`.right-panel`)**: 割合 25%。「ノード指標の推移（折れ線グラフ）」と「全体状態サマリー」カードを配置します。

## ページ表示ロジック

- **タブ切り替え**: `.tab-content` と `.tab-content.active` を JS と連携させ、異なる機能ページ（Dashboard / Errors / Injection）を瞬時に切り替えます。

## ダッシュボード共有ツールチップシステム

複数のダッシュボードカードが統一されたツールチップスタイルを再利用し、指標ラベルの横に補足説明を提供します:

| セレクタ | 説明 |
|--------|------|
| `.stat-label-row` | ラベルとツールチップのトリガー点を水平にインライン flex 配置、`gap: 0.3rem` |
| `.tooltip-anchor` | ツールチップ浮層のアンカーコンテナ、`position: relative`、内部にトリガーボタンと吹き出しを収容 |
| `.tooltip-trigger` | ツールチップボタン、`1rem` の円形、枠線 `1px solid --carbon-300`、`cursor: help`、ダークモード対応 |
| `.tooltip-bubble` | ツールチップの吹き出し、アンカーの下方に絶対配置、暗色背景に白文字、最大幅を制限、ホバーまたはフォーカス時に表示。ダークモードでは色を反転 |

## レスポンシブ対応

- **単一カラムへのフォールバック**: 幅が `2048px` 未満のとき、レイアウトは横方向の三列から縦方向の単一カラムのフローレイアウトへ自動的に切り替わり、すべてのパネル幅が自動的に 100% に広がり、小さい画面のデバイスでも指標を正常に閲覧できるようにします。
