# src/celestialflow_web/static/css/dashboard_analysis.css

> 📅 最終更新日: 2026/09/24

ダッシュボード左下の「グラフ分析情報」カードのスタイル定義を担当します。

> 注: グラフレベルの実行モード（`graphMode`）フィールドは削除された `scheduleMode` を置き換えたもので、`dashboard_analysis.ts` が `.analysis-value` を通じてレンダリングします。本 CSS ファイルには新しいセレクタは導入されていません。

## レイアウト設計 (`.analysis-info`)

- **構造**: 縦方向の `flex` レイアウトでキーと値のペアのリストを表示します。
- **フォント**: より多くのメタデータ情報を収容するため、小サイズフォント（`0.75rem`）を使用します。

## データ行のスタイル (`.analysis-row`)

- **左右揃え**: ラベル名（Label）は左寄せ、具体的な数値（Value）は右寄せ。
- **状態色 (`.analysis-value`)**:
  - `.ok`: 緑（`--jade-600`）。期待どおりであることを示します（例: DAG である）。
  - `.warn`: 赤（`--crimson-600`）。潜在的なリスクを示します（例: 閉路が存在する）。

## 関連モジュール

- データのレンダリングは `dashboard_analysis.ts` が担当し、このスクリプトはバックエンドから返された分析結果（DAG かどうか、グラフレベルの実行モード `graphMode` など）に応じて `ok` または `warn` クラスを動的に割り当てます。
