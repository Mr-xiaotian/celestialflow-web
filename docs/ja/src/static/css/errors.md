# src/celestialflow_web/static/css/errors.css

> 📅 最終更新日: 2026/09/24

「エラーログ」タブ下の検索ボックス、フィルター、データテーブル、およびページネーションコントロールのスタイル定義を担当します。

## 検索とフィルター (`.filter-container`)

- **レイアウト**: `flex` レイアウトを採用し、左側にタイトル、右側に検索入力ボックスとノードドロップダウンフィルターを表示します。
- **検索ボックス (`.error-search-input`)**:
  - 滑らかなトランジション効果を持ちます（`transition: all 0.2s`）。
  - **フォーカス状態**: フォーカスを得たとき、枠線色が濃くなり、背景色がわずかに変化して視覚的フィードバックを提供します。

## データテーブル (`#errors-table`)

- **構造**: 標準の HTML テーブルですが、モバイル/狭い画面では自動的にカードフローレイアウトに変換されます。
- **セルのスタイル**:
  - `.error-id`: グレー調で ID を表示し、視覚的ノイズを低減します。
  - `.error-cell`: エラー repr の表示専用で、等幅フォント（`monospace`）と赤色調（`Crimson`）を使用します。超長いエラー情報がレイアウトを壊すのを防ぐため、`max-width: 40ch` を設定し、省略記号（`ellipsis`）で切り詰めます。
  - `.retry-link`: エラー行の「リトライ」操作リンク。`--cornflower-600` の文字色で、ホバーまたはフォーカス時に下線が濃くなり、ダークモードでは `--cornflower-300` を使用します。
  - `.retry-disabled`: リトライ不可時のプレースホルダー文字。`--carbon-400` のグレー文字で、インタラクションフィードバックはなく、ダークモードでは `--carbon-500` を使用します。

## ページネーションコントロール (`.pager-container`)

- **ページ番号リンク (`.pager-link`)**: ホバーハイライトに対応します。
- **ページ送りボタン (`.pager-btn`)**:
  - 「前へ」と「次へ」のアイコンボタンを含みます。
  - **無効状態**: 最初のページまたは最後のページにあるとき、ボタンはグレーになりクリックできなくなります（`cursor: not-allowed`）。

## レスポンシブ設計

- **テーブルのカード化**: 幅が `2048px` 未満のとき、テーブルの `thead` は非表示になり、各行 `tr` は独立した角丸枠線付きのカードブロックになります。
- **擬似要素ラベル**: `::before { content: attr(data-label) }` を通じてテーブルの列名をカード内部に注入し、モバイルユーザーでもデータの意味を識別できるようにします。
- **エラーの展開**: カードモードでは、`.error-cell` の切り詰め制限が解除され（`white-space: normal`）、より多くの詳細を表示するため自動折り返しに変わります。
