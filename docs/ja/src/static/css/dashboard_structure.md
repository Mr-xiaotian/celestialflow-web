# src/celestialflow_web/static/css/dashboard_structure.css

> 📅 最終更新日: 2026/09/24

タスク構造図（Mermaid.js のレンダリング内容）のコンテナレイアウトおよびテーマ対応を担当します。

## コンテナレイアウト (`#mermaid-container`)

- **揃え方**: `flex` レイアウトを使用してコンテンツを水平方向および垂直方向に中央揃えにします。
- **スクロール対応**: `overflow-x: auto` を有効にし、大規模で複雑なグラフ構造において、ユーザーが横方向にスクロールして完全なトポロジーを閲覧できるようにします。

## Mermaid テーマ対応

Mermaid がレンダリングした SVG の内部スタイルは通常の CSS では上書きしにくいため、本ファイルは主にダークモード（`.dark-theme`）に対して重要なスタイルの強制上書きを行います:

- **矢印の色 (`.arrowMarkerPath`)**: ダークモードでは矢印の塗りつぶし色を `--carbon-200` に設定し、接続線の視認性を高めます。
- **ノードの文字 (`span`)**: ノード内部のテキスト色を強制的に `--carbon-300` に変更し、暗色背景のノード下での可読性を確保します。

## 関連モジュール

- 具体的なノードの背景色、枠線色、接続線のスタイル（`classDef`）は、`dashboard_structure.ts` 内で現在のテーマに応じて動的に生成される Mermaid コードで定義され、本 CSS ファイルには含まれません。
