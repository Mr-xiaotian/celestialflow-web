# src/celestialflow_web/static/css/dashboard_error_types.css

> 📅 最終更新日: 2026/09/24

ダッシュボードの「エラー種別分布」パネルのスタイル定義を担当し、ドーナツグラフと凡例によって各ノード下のエラー種別の割合分布を表示します。

## パネルコンテナ (`.error-types-card`)

エラー種別パネル全体のルートコンテナであり、内部のすべての子スタイルはネスト規則によってそのスコープ内に限定されます。

### パネルヘッダー (`.error-types-card-header`)

`flex` レイアウトを使用し、`space-between` で揃えます。左側はタイトル `.card-title`（`dashboard.css` で統一的に定義済み）、右側はノード絞り込みのドロップダウンです。

### ノードフィルター (`.error-type-node-filter`)

- 最小幅 `9rem`、角丸ボタン風。
- 枠線は `--carbon-300` を使用し、ダークモードでは `--carbon-600` に切り替わります。
- ダークモードでは背景色と文字色が反転し、視覚的な一貫性を保ちます。

### 総数統計 (`.error-type-total`)

- パネルヘッダーの下方に位置し、フォントサイズ `0.9rem`、グレーの文字。
- ダークモードでは自動的に淡い色に切り替わります。

## グラフ領域

### グラフシェル (`.error-type-chart-shell`)

- `flex` の中央揃えレイアウトを使用し、最小高さ `13rem`。
- Chart.js のドーナツグラフ（doughnut）のコンテナとして、安定した描画スペースを提供します。

### グラフキャンバス (`#error-type-chart`)

- ID セレクタを通じて幅と高さを `min(100%, 13rem)` に固定し、`!important` で Chart.js の自動計算サイズを上書きします。
- 異なるパネル幅においてもグラフが常に正方形を保ち、コンテナを超えないようにします。

## 凡例 (`.error-type-legend`)

縦に並ぶ凡例リストで、`flex-direction: column` と `0.5rem` の間隔を使用します。

### 凡例行 (`.error-type-legend-row`)

各行は色の円点、エラー種別名、件数の三項目を含みます:

| 子要素 | クラス名 | 説明 |
|--------|------|------|
| 色の円点 | `.error-type-legend-color` | `0.8rem × 0.8rem` の円形、`border-radius: 50%`、背景色は JS が動的に設定 |
| 種別名 | `.error-type-legend-label` | `flex: 1`、長いテキストの自動折り返しに対応（`word-break: break-word`） |
| 件数値 | `.error-type-legend-count` | 右揃え、等幅数字フォント（`tabular-nums`）、数値の比較が容易 |

凡例行の背景は `--carbon-50` の薄いグレーで、ダークモードでは `--carbon-800` の暗色に切り替わります。

## ダークモード対応

文字色、背景色、枠線色に関わるすべてのセレクタは、`.dark-theme &` のネスト規則を通じてダークモードのスタイルを提供し、統一して Carbon 色系統を使用します:

| 要素 | ライトモード | ダークモード |
|------|---------|---------|
| フィルター枠の背景 | `--white` | `--carbon-800` |
| フィルター枠の枠線 | `--carbon-300` | `--carbon-600` |
| フィルター枠/凡例の文字 | `--carbon-800` | `--carbon-100` |
| 補助文字（総数、件数） | `--carbon-600` | `--carbon-300` |
| 凡例行の背景 | `--carbon-50` | `--carbon-800` |

## 関連モジュール

- パネル全体のレイアウト（カードの角丸、影、タイトルのスタイル）は `dashboard.css` が統一的に定義します。
- グラフのデータとインタラクションのロジックは `dashboard_error_types.ts` が駆動し、ノードフィルターの切り替えに応じて Chart.js のドーナツグラフを再レンダリングし、凡例を更新する役割を担います。
