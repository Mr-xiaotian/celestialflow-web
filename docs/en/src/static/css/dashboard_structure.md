# src/celestialflow_web/static/css/dashboard_structure.css

> 📅 Last Updated: 2026/09/24

Handles the container layout and theme adaptation of the task structure graph (Mermaid.js rendered content).

## Container Layout (`#mermaid-container`)

- **Alignment**: Uses a `flex` layout to center the content horizontally and vertically.
- **Scroll support**: Enables `overflow-x: auto`, ensuring that users can scroll horizontally to view the complete topology for large, complex graph structures.

## Mermaid Theme Adaptation

Because the internal styles of the SVG rendered by Mermaid are difficult to override with regular CSS, this file mainly performs forced overrides of key styles for dark mode (`.dark-theme`):

- **Arrow color (`.arrowMarkerPath`)**: In dark mode, sets the arrow fill color to `--carbon-200` to improve the visibility of the connections.
- **Node text (`span`)**: Forces the text color inside nodes to `--carbon-300`, ensuring readability on dark background nodes.

## Related Modules

- The specific node background colors, border colors, and connection styles (`classDef`) are defined in the Mermaid code dynamically generated by `dashboard_structure.ts` based on the current theme, not in this CSS file.
