# src/celestialflow_web/static/ts/i18n.ts

> 📅 Last Updated: 2026/09/24

Internationalization module, responsible for maintaining multilingual (Chinese, English, Japanese) translation data, managing the current language state, and automatically updating DOM text.

## Type Definitions

### `Lang`
Supported language identifiers: `"zh-CN"` | `"en"` | `"ja"`.

## Global Variables

| Variable | Type | Description |
|------|------|------|
| `currentLang` | `Lang` | Currently selected language identifier, default `"zh-CN"` |
| `translations` | `Record<Lang, Record<string, string>>` | Translation dictionary containing all languages |

## Core Functions

### `setLang(lang)`

Switches the global language setting.

- **Parameters**: `lang: Lang` - Target language identifier.
- **Behavior**: Updates `currentLang` and synchronously modifies the `lang` attribute of the `<html>` tag.

---

### `t(key, ...args)`

Gets the text in the current language by translation key, supporting simple placeholder substitution.

- **Parameters**:
  - `key: string` - Translation key name.
  - `...args: string[]` - Argument list used to replace `{0}`, `{1}`...
- **Returns**: The translated string. If the corresponding key is not found, returns the key name itself.
- **Fallback mechanism**: If the key does not exist in the current language, it tries to fall back to `zh-CN`.

---

### `applyI18nDOM()`

Scans the whole page for elements with a specific `data-i18n` attribute and applies translations.

**Supported attributes:**
- `data-i18n`: replaces `textContent`.
- `data-i18n-placeholder`: replaces `placeholder`.
- `data-i18n-title`: replaces the `title` attribute.
- `data-i18n-aria-label`: replaces the `aria-label` attribute.

In addition, this function also synchronously updates `document.title`.

## Translation Key Groups

- `app.*`: application-wide text (title, etc.)
- `settings.*`: settings panel related
- `tab.*`: tab names
- `card.*`: card titles
- `summary.*`: summary data labels
- `errors.*`: error log related
- `injection.*`: task injection related
- `analysis.*`: graph analysis related (including graph mode text)
- `status.*`: node status related (including labels for execution mode, concurrency, pending amount, etc.)
- `chart.*`: chart related
- `errorTypes.*`: error type distribution card related
- `structure.*`: structure graph related
- `interval.*`: time interval options

## Usage Examples

### Usage examples of t() / setLang() / applyI18nDOM()

The following examples show how to use the three core functions of the i18n module in the browser console:

```typescript
// 1. t(): get the translated text for the current language
console.log(t("app.title"));       // "任务图监控系统" (currently zh-CN)
console.log(t("settings.saveSuccess")); // "设置已保存"

// 2. t() supports placeholder substitution
// translation key "injection.successBatch": "已成功提交 {0} 个节点草稿"
console.log(t("injection.successBatch", "3"));
// "已成功提交 3 个节点草稿"

// 3. t()'s fallback mechanism
// if the current language (e.g. ja) lacks a key, fall back to zh-CN
// if zh-CN also lacks it, return the key name itself
console.log(t("nonexistent.key"));  // "nonexistent.key"

// 4. setLang(): switch the global language
setLang("en");
console.log(currentLang);           // "en"
console.log(document.documentElement.lang); // "en"
console.log(t("app.title"));       // "Task Graph Monitor"

setLang("ja");
console.log(t("app.title"));       // "タスクグラフモニター"

// 5. applyI18nDOM(): scan the whole page and update translations
// assume the HTML contains:
//   <h1 data-i18n="app.title"></h1>
//   <input data-i18n-placeholder="errors.searchPlaceholder">
//   <div data-i18n-title="settings.tooltip"></div>
//
// after calling applyI18nDOM():
//   <h1>任务图监控系统</h1>
//   <input placeholder="搜索错误或任务">
//   <div title="设置"></div>

// 6. complete language switching flow
function switchLanguage(lang: Lang) {
    setLang(lang);                    // update currentLang and <html lang>
    applyI18nDOM();                   // update all data-i18n elements
    document.title = t("app.title"); // update the page title
}

// switch to English
switchLanguage("en");

// switch to Chinese
switchLanguage("zh-CN");

// 7. check whether a translation key exists
function hasTranslation(key: string, lang?: Lang): boolean {
    const targetLang = lang || currentLang;
    return !!translations[targetLang]?.[key];
}

console.log(hasTranslation("app.title"));                 // true
console.log(hasTranslation("app.title", "en"));           // true
console.log(hasTranslation("app.title", "ja"));           // true
console.log(hasTranslation("nonexistent.key", "zh-CN"));  // false
```
